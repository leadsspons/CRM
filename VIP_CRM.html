🔄 데이터 초기화

📄 DocuSign 계약 자동 등록

🖥️ 서버 모드 (시작.bat 실행 중)
DocuSign 관리자 → Connect 설정에서
아래 URL을 Webhook 주소로 등록하세요:
http://localhost:3000/api/docusign-webhook
📂 오프라인 모드 (이 HTML 파일)
DocuSign에서 완료된 계약 JSON을
붙여넣기하면 고객이 자동 등록됩니다.
📋 DocuSign 템플릿 커스텀 필드 설정 (Text Custom Fields)
${[['회사명','company (회사/상호명)'],['대표자','담당자 이름'],['카테고리','company / doctor / goldenvisa / realestate'], ['계약금액','$8,500 형식'],['결제계좌','KB국민은행 등'],['한국연락처','010-XXXX-XXXX'], ['두바이번호','+971-50-XXX-XXXX'],['이메일','이메일 주소'],['입국예정일','2026.07.01 형식'] ].map(([k,v])=>`
${k}
${v}
`).join('')}
📖 DocuSign Connect 설정 방법:
1. DocuSign 관리자 → Settings → Connect → Add Configuration
2. URL: http://서버IP:3000/api/docusign-webhook
3. Trigger: Envelope Completed
4. Include: Custom Fields, Recipients
5. 계약서 템플릿에 위 커스텀 필드를 추가해두면 서명 완료 시 CRM 자동 등록됩니다 🎉
